What the script sets up

Automated steps across Windows, macOS, and Linux.

01 / Runtime

Ollama & GPU flags

Installs Ollama if missing, enables OLLAMA_FLASH_ATTENTION=1 and 24h keep-alive, and waits for port 11434.

02 / Models

65% memory filtering

Reads RAM and VRAM, lets you choose Express presets or pick from the live Ollama catalog, and pulls nomic-embed-text for @codebase.

03 / Editor

Continue YAML v1

Installs Continue.continue across detected editors, backs up existing configs, writes ~/.continue/config.yaml, and skips API-key onboarding.
